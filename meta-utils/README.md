# Meta utils

Технические утилиты, часть тестирующей инфраструктуры курса. Свои тесты — `cabal test meta-utils-test`.

| Модуль | Что даёт |
|---|---|
| `TodoException` | заглушка `todo` для термов: задача с ней получает статус TODO, а не FAILED |
| `TodoMacro` | `todoImpl ''Class ''Type` — инстанс-заглушка, все методы которого бросают `todo` |
| `TypeCheck` | проверка задач, где ответ — тип; заглушка `Todo` для типов |
| `ClassDispatcher`, `PP` | служебное |

`MetaUtils` — фасад: реэкспортирует всё, кроме `TypeCheck`. Его модули уровней и тесты импортируют явно, чтобы имя `Todo` не сталкивалось с одноимёнными заглушками в домашках, у которых она своя.

## TypeCheck: задачи, где ответ — тип

Требования к таким проверкам: неверный ответ не ломает сборку тестов, заглушка даёт статус TODO, сообщение о провале не печатает ожидаемый ответ.

Сравнивается форма типа — строка, в которую Template Haskell рендерит дерево типа. Имена переменных в форму не попадают, поэтому ответ сверяется с точностью до переименования. Что именно считается одинаковым и что различается, записано в шапке модуля и проверено в `test/TypeCheckSpec.hs`.

Синоним типа:

```haskell
-- src/Level3.hs
type Pair a b = Todo

-- test/SpecLevel3.hs
assertShape "3.1 Pair" "2 (forall v3 (-> (-> v1 (-> v2 v3)) v3))" $(synonymShape ''Pair)
```

Ожидаемую строку не пишут руками: её печатают с эталона, например в `cabal repl homework-test` командой `putStrLn $(synonymShape ''Pair)` на ветке `solutions`.

Предсказание типа выражения. Студент пишет сигнатуру при заглушке, эталон в тесте записан выражением без сигнатуры, и его тип выводит GHC:

```haskell
-- src/Level1.hs
constId :: Todo        -- замените Todo типом выражения `const id`
constId = todo "1.6"

-- test/SpecLevel1.hs
reference = const id   -- без сигнатуры

assertShape "1.6" $(shapeOfType 'reference) $(shapeOfType 'constId)
```

Эталон должен лежать в модуле, который скомпилирован раньше модуля со сплайсом, или выше по файлу за объявлением-сплайсом: `reify` видит только уже проверенные имена. Если у выражения есть ограничения классов, эталон записывают функцией с аргументом или включают `NoMonomorphismRestriction`, иначе GHC подставит тип по умолчанию.

Тип без переменных можно сравнить и через `Typeable`: `typeIs @Expected @Answer "1.1"`.
